## How the ranking works

- Repositories are collected from the GitHub Search API using five queries: `topic:claude-skills`, `topic:agent-skills`, `topic:ai-skills`, `claude skills in:name,description`, and `agent skills in:name`.
- Results are filtered to repositories whose name, description or topics mention both skills and an AI agent (Claude, Codex, Cursor, Gemini, LLM or AI).
- Duplicates are merged, then sorted by star count.
- The trending section covers repositories created in the last 30 days, sorted by stars.
- The whole pipeline runs hourly via `.github/workflows/update.yml` and commits the refreshed README automatically.

## Get your skills listed

Add the `claude-skills` or `agent-skills` topic to your repository and make sure your name or description contains the word "skills". The next hourly run will pick it up. You can also trigger a run manually from the Actions tab.

## FAQ

**How often is the leaderboard updated?**
Every hour, by a GitHub Actions cron job. The timestamp at the top of the table shows the last refresh.

**How do I get my skill repository listed?**
Add the `claude-skills` or `agent-skills` topic to your repo and mention skills in the repo name or description. The next hourly run picks it up automatically, or trigger a run manually from the Actions tab.

**Is the data free to reuse?**
Yes. The JSON and llms.txt files are published in the repository under the MIT license.

**Is this affiliated with Anthropic?**
No. This is an independent community tracker built on the public GitHub Search API.
